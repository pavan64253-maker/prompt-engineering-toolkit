# One-shot prompting

## What it means
Give the model one example of the input and the kind of output you want, followed by the real task.

## When to use it
Use it when a short example can clarify tone, layout, or a simple transformation.

## Small example
Show one informal sentence and its professional rewrite, then ask the model to rewrite another sentence.

## Key takeaway
One well-chosen example can make an unstated pattern clear.
