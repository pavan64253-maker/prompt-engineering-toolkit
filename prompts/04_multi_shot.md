# Multi-shot prompting

## What it means
Provide many examples before the task to reinforce a detailed or consistent pattern.

## When to use it
Use it when categories have similar boundaries or outputs need to follow a steady convention.

## Small example
Show multiple support tickets tagged Billing, Delivery, Technical, Account, or Returns, then tag a new ticket.

## Key takeaway
More examples can improve pattern clarity, but keep them relevant and consistent.
