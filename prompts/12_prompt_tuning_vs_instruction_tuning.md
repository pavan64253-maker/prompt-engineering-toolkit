# Prompt tuning vs. instruction tuning

## What it means
Prompt engineering edits the input at use time. Prompt tuning and instruction tuning adapt a model through training processes.

## When to use it
Learn this distinction when comparing what an API user can change with how a model can be adapted.

## Small example
An API user can refine “Summarize this text in three bullets.” Training teams can instead adapt model behavior using prompt-tuning or instruction-tuning methods.

## Key takeaway
Prompt engineering is usually an API-user activity; prompt tuning and instruction tuning are training-side concepts.
