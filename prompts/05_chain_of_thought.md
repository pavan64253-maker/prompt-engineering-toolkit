# Chain-of-thought prompting

## What it means
Ask for a task to be worked through in steps, such as showing a concise calculation.

## When to use it
Use it for arithmetic or comparisons where a visible, checkable explanation is useful.

## Small example
Ask for break-even units and request the formula, substituted values, and final result.

## Key takeaway
Request concise, verifiable steps rather than relying on an unexplained answer.
