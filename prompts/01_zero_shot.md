# Zero-shot prompting

## What it means
Give the model a task directly, without showing examples of the desired answer.

## When to use it
Use it for familiar, straightforward tasks such as summarizing, rewriting, or brainstorming.

## Small example
Ask, “Summarize this paragraph in two sentences,” then provide the paragraph.

## Key takeaway
Start with a clear direct instruction; add examples only if the result needs more guidance.
