# Few-shot prompting

## What it means
Provide a few input-and-output examples so the model can follow a pattern.

## When to use it
Use it for small classification or formatting tasks when examples clarify the labels.

## Small example
Show several reviews labeled Positive, Negative, or Neutral, then request a label for a new review.

## Key takeaway
Use representative examples that cover the kinds of answers the task needs.
