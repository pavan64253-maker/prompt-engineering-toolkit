# Prompt structuring basics

## What it means
Organize the prompt into sections such as Role, Task, Context, Constraints, and Output Format.

## When to use it
Use structure when a task has several requirements or the response needs a predictable shape.

## Small example
Ask a small-business coach for a marketing plan, explain the business context, limit the budget, and request three numbered actions.

## Key takeaway
Clear sections make requirements easier for both people and models to follow.
